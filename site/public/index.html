Feed Cleaner

A Chrome extension that collapses likely-bot posts on X behind a click. Nothing is deleted or hidden for good: one click shows the post.

Download the extension (.zip)

What it does

  • Checks each post on your timeline against a few signals read from the page.
  • Collapses posts that look like bots behind a “show post” bar.
  • Leaves reply threads intact, so conversations still make sense.

What it doesn’t do

  • It doesn’t detect misinformation. It only guesses whether an account is a bot.
  • It doesn’t work on mobile, only desktop Chrome and other Chromium browsers.

Honesty note

The thresholds are guesses. They haven’t been tuned or validated yet, so expect it to collapse some real people and miss some bots.

If you see a wrong collapse, or a bot it missed, please send me the post link. That’s the most useful feedback you can give.

Install (about 1 minute)

  1. Download the zip and unzip it. You’ll get a folder.
  2. Open chrome://extensions in a new tab. You have to type or paste it; links to it are blocked.
  3. Turn on Developer mode (toggle, top right).
  4. Click Load unpacked and pick the unzipped folder.
  5. Open or reload x.com. Likely-bot posts now show as collapsed bars.

Chrome may warn about developer-mode extensions on startup. That’s expected for anything not installed from the Chrome Web Store. To update, download the new zip, replace the folder, and click the reload icon on the extension’s card.

Uninstall

Go to chrome://extensions and click Remove on Feed Cleaner.
